## Pembaruan: grafik makan dan obat; tampilan 90 hari; skala teks 2.0

- **Makan:** batang karbohidrat tercatat per hari. Batang pekat = semua item punya data; berongga = hanya sebagian (nilai sebenarnya ≥); "?" = ada makan tetapi tak ada data karbohidrat; "–" = tidak ada catatan makan.
- **Obat:** batang bertumpuk jumlah konfirmasi (pekat = diminum, berongga = dilewati). Tanpa persentase kepatuhan; hari tanpa konfirmasi = "–".
- **90 hari:** sel sempit kini blok pucat (kosong) vs blok pekat (ada catatan); sebelumnya garis tepi 1 px hilang.
- **Skala teks 2.0:** tes widget (tanpa overflow, pembacaan tetap tampil); tinggi pembacaan dinaikkan ke 76 dp.
- **Mode gelap:** aplikasi belum memiliki tema gelap (`darkTheme`/`ThemeMode` tidak ada), jadi belum ada yang bisa dicek; ini fitur terpisah.
- Tes: 97 Flutter lulus (4 tes baru di `trends_test.dart`), `analyze` bersih. Emulator: kartu Makan/Obat dan 90 hari dilihat dengan data sintetis (9 makan lewat API, 9 konfirmasi obat lewat SQL di DB dev).
