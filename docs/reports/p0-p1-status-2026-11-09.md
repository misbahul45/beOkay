Status: **DIMULAI — irisan pertama selesai** (kalkulator porsi, pencarian pangan lokal-dahulu, adapter Open Food Facts/USDA, API barcode). Rinciannya di `docs/audits/p1-readiness-audit.md`; sisanya belum dikerjakan. 2. P1-03 kalkulator gizi murni (Decimal, cakupan UNKNOWN/PARTIAL/COMPLETE) — tidak butuh jaringan; bisa dites penuh.
3. P1-01/02 ingest PDF Tabel Komposisi Pangan → tabel referensi terverifikasi + embedding `mistral-embed` (pgvector sudah ada di image) → pencarian lokal-dahulu; adapter USDA/Open Food Facts (perlu kunci USDA); web fallback hanya setelah kunci dan kebijakan SSRF.
4. Health Connect (Android) setelah ada data uji terkontrol di emulator; HealthKit tidak bisa diverifikasi di mesin ini.
